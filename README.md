# naught

`naught` is the custody-stage repository for content held in **naught space** between [Nullus](https://github.com/Eaprime1/nullus)'s nullification (authorized by [Custos](https://github.com/Eaprime1/custos)) and the downstream Zero space repo. Its current responsibility is the **`unknown` → `naught_known`** transition: hold incoming items without erasure, preserve traceability to origin, and produce new states by `gas_transfer` rather than in-place mutation. The scaffold here is intentionally lean while the owner decides how much additional naught-space responsibility should live in this repo; see [`schema/naught_intake.json`](schema/naught_intake.json) for the minimum custody shape and [`docs/open-questions.md`](docs/open-questions.md) for the questions that remain explicitly unresolved.
