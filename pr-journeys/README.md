# pr-journeys

Records of PR life in this repo — closure notes today, full auto-written
journey documents once this repo's `finalize-pr.yml` grows the same
capability custos's has.

**Current state:** this repo's `finalize-pr.yml` checks that review
threads are resolved and applies the `finalized` label — it does not yet
write a journey document to this folder automatically. Custos's fuller
`finalize-pr.yml` (which does write full journeys on `@claude finalize`)
has not been ported here yet — see `docs/repo-hygiene-routine.md` history
for that open thread.

## What Lives Here Today

`closures/` — stale-branch closure notes, one per closed branch, per
`docs/stale-branch-closure.md`. This is real and working now, independent
of the fuller auto-journey system.

## Naming (once the fuller system lands)

```
YYYYMM_PR{N}_{slug}.md
```

Example: `202608_PR18_repo-hygiene-upgrade.md`
